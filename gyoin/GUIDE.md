# 장유중앙교회 교인앱 — 설치·연결 가이드

교인앱 = 성도 폰 홈 화면 아이콘 하나로 주보·말씀·동아리 앱을 열고, QR로 출석을 체크하는 앱입니다.
화면은 GitHub Pages, 출석 기록은 구글 시트(+Apps Script)에 저장됩니다.

## 1. 구글 시트 연결 (출석 저장) — 연결 완료
- 시트: 목사님 구글 드라이브의 「장유중앙교회 출석」 → `출석` 탭에 쌓입니다.
- 코드: 그 시트의 **확장 프로그램 → Apps Script**에 `apps-script/Code.gs`가 들어 있고, 웹 앱(실행: 나 / 액세스: 모든 사용자)으로 배포되어 있습니다.
- 배포 주소는 `config.js`의 `GAS_URL`에 들어 있습니다.

코드를 나중에 고칠 때: Apps Script 편집기에 **전체 붙여넣기 → 저장 → 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (주소는 그대로).

### 시트에 쌓이는 칸
`타임스탬프 · 날짜 · 성명 · 소속 목장 · 연락처 뒷자리 · 예배 구분 · 스캔 위치/경로 · 동반 여부`

### 예배 시간표 (Code.gs 위쪽 SERVICES, app.js의 serviceOf와 같게)
| 예배 | 실제 시작 | 출석으로 인정하는 시간 |
|---|---|---|
| 주일 1부 | 일 오전 8:50 (은혜홀) | 08:00~10:15 |
| 주일 2부 | 일 오전 10:50 (은혜홀) | 10:15~13:00 |
| 주일 오후찬양 | 일 오후 2:00 (은혜홀) | 13:00~16:00 |
| 수요예배 | 수 저녁 7:30 (은혜홀) | 18:30~21:30 |
| 금요심야기도회 | 금 저녁 9:00 (은혜홀) | 20:00~24:00 |
| 새벽기도회 | 월~토 오전 5:30 (믿음홀) | 04:30~07:00 |
| 그 외 | | 기타 |

시간을 고칠 곳은 **Code.gs의 SERVICES**와 **app.js의 serviceOf 함수** 두 군데입니다. 시트에 저장되는 예배 구분은 Code.gs(서버 시각) 기준입니다.
유초등부(11:00)·청소년부(9:00)는 믿음홀 QR로 찍으면 "주일 1부/2부 + 믿음홀"로 기록됩니다.

### 중복 방지
같은 날짜·같은 예배·같은 사람(이름+뒷자리)이 **5분 안에** 다시 찍으면 저장하지 않고 "이미 출석"으로 알려 줍니다. 5분이 지나면 다시 기록됩니다. "예배당 1회만"으로 바꾸려면 Code.gs의 `DEDUP_MINUTES`를 `0`으로 하세요.

## 2. GitHub에 올리는 곳
교인앱은 `jjc-app` 저장소의 `gyoin/` 폴더에 올라갑니다. (작업 원본은 `~/jangyu-church/gyoin`, 올릴 때 `jjc-app/gyoin`으로 복사 후 push)
주소: `https://jangyu-church.github.io/jjc-app/gyoin/`

## 3. 사역자 · 목회자 PIN
PIN은 두 개입니다. **사역자 PIN**은 사역자용 앱만, **목회자 PIN**은 사역자용 + 목회자 전용(목장관리앱, 건강 물음표)까지 모두 엽니다.
파일에는 PIN 자체가 아니라 SHA-256 값만 적습니다. PIN을 바꾸려면 아무 웹페이지의 개발자도구 콘솔에서 아래를 실행(1234 자리에 새 PIN)해 나온 값을
- `config.js`의 `STAFF_PIN_SHA256`(사역자) 또는 `PASTOR_PIN_SHA256`(목회자)
- `apps-script/Code.gs`의 `PIN_HASHES` (목장별 출석 현황용, 구글에 다시 배포)

두 곳에 넣습니다.

```js
crypto.subtle.digest('SHA-256', new TextEncoder().encode('jjc:1234')).then(b => console.log([...new Uint8Array(b)].map(x => x.toString(16).padStart(2, '0')).join('')))
```

PIN은 가벼운 잠금입니다. 숫자 4자리라 작정하고 풀려면 풀 수 있으니, 정말 민감한 화면(목장관리·재정 관리·태신자 출석부)은 각 앱 자체 비밀번호가 지켜 줍니다.

## 4. 본당 QR 만들기·붙이기
1. `tools/qr-poster.html`을 브라우저로 엽니다. (GitHub Pages에 올린 뒤 `…/jjc-app/gyoin/tools/qr-poster.html`로 열어도 됩니다.)
2. 주소 확인 → 장소 `은혜홀` → **인쇄하기** (A4 권장, 출입구와 좌석 근처에 부착)
3. QR 안에는 `https://jangyu-church.github.io/jjc-app/gyoin/?action=checkin&loc=main_hall` 이 들어 있습니다. 믿음홀(새벽기도·유초등부·청소년부)은 `loc=faith_hall`로 따로 만들어 붙이면 시트의 "스캔 위치"에 구분되어 기록됩니다. 새 장소를 더 만들려면 `config.js`의 `LOCATIONS`와 Code.gs의 `LOCATIONS` **둘 다** 추가하세요.

## 5. 성도에게 안내할 말
- 아이폰: 사파리로 주소 열기 → 공유(□↑) → **홈 화면에 추가**
- 안드로이드: 크롬으로 열기 → **홈 화면에 추가/설치**
- 처음 한 번 이름·목장·휴대폰 뒷자리 4자리 입력
- 예배 때 앱의 **[예배 QR 출석 체크]**를 누르거나 폰 기본 카메라로 본당 QR 찍기

## 시즌 앱 열고 닫기 (태신자 작정 · 작정 현황 · 감사 챌린지 · 대림절 묵상)
`apps.json`에서 해당 앱의 `open`(여는 날)과 `close`(닫는 날)를 `"2026-11-29"`처럼 적으면 그 기간에만 홈에 보입니다.
- `open`이 비어 있으면 숨겨집니다. `close`가 비어 있으면 연 뒤로 계속 보입니다.
- 보일 앱이 하나도 없으면 "절기 · 전도" 묶음 자체가 숨겨집니다.
- 날짜가 되면 자동으로 나타나므로 미리 적어 두고 push하면 됩니다.

## 목자 앱 (목장별 열쇠 링크)
목장 열쇠가 들어 있는 링크는 목원 연락처로 이어지므로 **이 저장소(apps.json)에는 적지 않습니다.** GitHub에 올린 파일은 누구나 볼 수 있기 때문입니다.
- 목자님은 사역자·목회자 탭 → 목자 앱 → **링크 등록**을 누르고, 카톡으로 받은 "우리 목장 앱" 링크를 한 번 붙여 넣습니다.
- 열쇠는 그 폰에만 저장되고, 다음부터는 **우리 목장 열기**로 바로 열립니다.
- 교역자 화면에서 [새 링크]로 열쇠를 바꾸면, 목자님이 **링크 변경**으로 새 링크를 다시 붙여 넣으면 됩니다.

## 6. 알아 둘 점 (솔직한 한계)
- **아이폰**: 홈 화면에 설치한 앱과 사파리는 저장 공간이 따로입니다. 앱에서 등록하고 기본 카메라로 QR을 찍으면 사파리가 열려 **정보를 한 번 더 입력**해야 합니다. 아이폰 성도에게는 "앱 안의 출석 버튼"을 쓰도록 안내하세요.
- 출석 주소(/exec)는 누구나 호출할 수 있는 구조라, 이름만 알면 대신 출석을 넣을 수 있습니다(비밀번호 없는 방식의 한계). 이상한 기록은 시트에서 지우면 됩니다.
- 시트에는 이름·목장·전화 뒷자리가 쌓이므로 시트 공유는 사역자에게만 하세요.
- 앱 안의 외부 앱 링크 중 `url`이 빈 것(건강 물음표, 등불 스터디, 태신자 작정 등)은 "준비 중"으로 보입니다. `apps.json`에 주소를 넣고 push하면 열립니다.
- `running`, `finance-claim`, `mokja`는 기존 주소 규칙으로 추정해서 넣었습니다. 열리는지 확인해 주세요.
- 화면을 고쳐 올릴 때는 `sw.js` 맨 위 `VERSION` 숫자와 `index.html`의 `?v=` 숫자 세 군데를 같이 올리세요. 그래야 폰에 예전 파일이 남지 않습니다.
